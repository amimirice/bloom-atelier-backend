# Bloom Atelier — Backend

### Spring Boot REST API for a Luxury Bridal E-Commerce Website

Backend application for Bloom Atelier, a full-stack e-commerce portfolio project focused on a refined and responsive bridal bouquet shopping experience.

## Tech Stack

- Java
- Spring Boot
- Spring Security
- MySQL
- Gradle
- REST APIs
- AWS EC2 & RDS
- Docker

## Key Features

- REST APIs for product listing and product details
- Product data management with MySQL
- Shopping bag and transaction-related backend functionality
- Checkout request handling
- Authentication and API security integration
- Backend integration with the React frontend

## Project Architecture

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Java, Spring Boot
- **Database:** MySQL (AWS RDS)
- **Deployment:** AWS Amplify (Frontend), AWS EC2 with Docker (Backend)
